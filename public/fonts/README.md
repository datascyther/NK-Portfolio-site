# Neue Montreal

`PPNeueMontreal-Variable.woff2` is the variable upright webfont used for the local portfolio preview, retrieved from Pangram Pangram’s official specimen page on November 14, 2026.

Specimen: https://pangrampangram.com/products/neue-montreal
Asset: https://pangrampangram.com/cdn/shop/files/PPNeueMontreal-Variable_b3ebe68c-91e0-4337-a3bc-c2a15b5e395b.woff2?v=1182376259239852185

The variable font is served locally with a normal 100–900 weight range, font-display: swap, and an HTML preload. Font licensing is managed by the site owner. A replacement webfont build can use the same path.
